# Lisensi pihak ketiga

Dokumen ini mempertahankan pemberitahuan lisensi dari skill pengembangan yang dipasang di repository. Installer skill dapat menyalin direktori skill tanpa berkas `LICENSE` di akar repository sumber.

Lisensi MIT pada akar mini project berlaku untuk kode project yang dilisensikan oleh pembuatnya. Lisensi tersebut tidak melisensikan ulang logo milik pengguna maupun paket skill pihak ketiga. Setiap aset dan paket tetap mengikuti hak serta lisensi sumbernya. Berkas lisensi yang sudah disertakan, termasuk `.agents/skills/ui-styling/LICENSE.txt`, tetap dipertahankan. Lihat juga [catatan aset](ASSETS.md).
