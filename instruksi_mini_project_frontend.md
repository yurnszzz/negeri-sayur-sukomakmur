# INSTRUKSI MINI PROJECT
# STUDY CLUB FRONTEND BASIC

### 1. Jenis Tugas
Mini Project dikerjakan secara **individu.**

### 2. Deadline Tugas
Deadline Jumat, 23 Oktober 2026 23:59 WIB

### 3. Tempat Pengumpulan Tugas
Kelas Peminatan Frontend pada Dignition Veterantech.

### 4. Deskripsi Tugas
Buatlah sebuah tampilan layout website destinasi wisata dengan tema tampilan sesuai kreativitas masing-masing menggunakan HTML dan CSS yang mencakup beberapa materi berikut:
a. Tag Semantic HTML
b. CSS Layouting (Flexbox atau Grid)
c. Teks (seperti h1–h6 dan p)
d. List (ordered dan unordered list)
e. Table
f. Media (gambar, video, atau audio)
g. Link (intra-page, external, dan email link)
h. Form sederhana

### 5. Ketentuan Tugas
* Pembuatan halaman website destinasi wisata **menggunakan syntax HTML,** dan **CSS jika mampu** (nilai plus).
* Website hanya menampilkan **1 destinasi wisata utama** (misal: “Pantai Kuta”, “Gunung Bromo”, “Danau Toba”).
* Layout halaman **wajib memuat elemen berikut:**
  a. **Header** – berisi nama atau logo website (contoh: *Explore Indonesia*).
  b. **Gambar atau Video** – menampilkan keindahan tempat wisata.
  c. **Judul destinasi wisata.**
  d. **Deskripsi / informasi singkat** tentang tempat wisata.
  e. **Tabel harga tiket, fasilitas, atau jadwal buka.**
  f. **List aktivitas menarik** yang dapat dilakukan di lokasi wisata.
  g. **Link eksternal** menuju situs resmi pariwisata atau Google Maps.
  h. **Link Internal** – ke Internal Page (halaman yang sama)
  i. **Form pemesanan / kontak sederhana** (nama, email, pesan).
  j. **Bagian rekomendasi wisata lain** – berisi beberapa gambar dan nama destinasi.
  k. **Footer** – berisi nama pembuat website dan media sosial.
* Dalam pembuatannya tidak wajib untuk mencakup keseluruhan dari materi yang ada pada point Deskripsi Tugas, namun jika mencakup semua lebih baik.
* Format penamaan file source code berupa: **Source Code_Nama Mentee.html/css**
